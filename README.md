## Сайтты пайдалану

1. Қажетті модульді ашып, тапсырмалардың алдындағы теорияны оқыңыз.
2. Тапсырманы ашыңыз. Мысалдың нәтижесі бірден көрсетіледі.
3. Өз деректеріңізді тексеру үшін сандарды бос орынмен бөліп жазыңыз. Әр жол 0-рангтен басталатын бір процеске сәйкес келеді. Кіріс деректері жоқ процесс үшін `—` белгісін қойыңыз.
4. **Іске қосу** түймесін басыңыз. Нәтижеде қос нүктенің алдында процесс рангі көрсетіледі. **Мысалды қалпына келтіру** түймесі бастапқы деректерді қайтарады.

Сайт MPI процестерінің дерек алмасуын браузерде модельдейді. Веб-тапсырмаларды орындау үшін ештеңе орнатудың қажеті жоқ. C бағдарламасын нақты MPI ортасында іске қосқыңыз келсе, **Бастапқы код** бөлімінен тапсырманы ашып, сол жерде берілген құрастыру және іске қосу пәрмендерін қолданыңыз.

## MPI көмекшісі

Беттің төменгі оң жағындағы **Көмекші** түймесін басыңыз. Мысалы, «MPI_Gather деген не?», «4-модуль», «MPIBegin20 мысалы» немесе «Қате шықса не істеймін?» деп сұраңыз. Көмекші MPI-дің 45 атауына түсініктеме береді және 36 тапсырманың шешу жолын, кіріс мысалын немесе C кодының сілтемесін көрсетеді. Ол браузерде дайын жауаптармен жұмыс істейді және сұрақтарды серверге жібермейді.

## Жоба файлдары

- `index.html` — практикумның басты беті.
- `module-1.html`–`module-5.html` — теория мен интерактивті тапсырмаларға арналған модуль беттері.
- `code.html` — тапсырмалардың C тіліндегі бастапқы коды.
- `styles.css` және `app.js` — барлық бетке ортақ дизайн, тапсырмаларды есептеу, іздеу және көмекші.
- `README.md` — жобаның сипаттамасы мен пайдалану нұсқаулығы.

Интернетсіз пайдалану үшін ZIP архивін бір қалтаға шығарып, сол жердегі `index.html` файлын браузерде ашыңыз.
